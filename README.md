# AdhyatmaVeda — Sanatana Dharma Sadhana Junction

A comprehensive, full-featured Progressive Web App (PWA) designed as the definitive "One-Stop Junction" for both beginner spiritual aspirants (Self-Upasana) and academic/advanced researchers in Sanatana Dharma, Tantra, and Regional Folk Traditions.

## Features

### Safety & Guidance Engine
- **Safety Badge Matrix**: Every ritual, stotram, and mantra displays one of 3 safety levels — Green (home safe), Amber (rules apply), Red (Diksha required).
- **Sankalpa Generator**: Interactive form that compiles a proper Sankalpa statement.
- **Altar Setup Guides**: Visual layouts for Smarta, Vaishnava, Shaiva, and Shakta home altars.
- **Mudra Library**: Visual guides for home mudras with benefits and meanings.

### Deep Domain Knowledge Base
- **Vaishnava Domain**: Sampradayas, Dashavatara, deities, practices.
- **Shaiva Domain**: Schools, 12 Jyotirlingas, forms of Shiva, practices.
- **Shakta Domain**: Kali Kula vs. Sri Kula, 10 Mahavidyas, Ashta Matrikas, 51 Shakti Peethas.
- **Folk & Regional Archive**: Bengali, Tulu Nadu, Tamil, Himalayan, and Maharashtrian folk deities.

### 90-Text Scriptural Library
- 30 Vaishnava, 30 Shaiva, and 30 Shakta texts with Sanskrit, IAST transliteration, English translation, and source archive links.

### Interactive Tools
- **Digital Japa Counter**: Haptic feedback, progress wheel, targets (11/21/108/custom/Savalakh), temple bell, ambient sounds, lifetime logger.
- **Ishta & Path Finder Quiz**: 7-stage evaluation across Vaishnava, Shaiva, Shakta, and Smarta temperaments.
- **Pronunciation Tutor**: Sanskrit akshara guide with audio and mantra rhythm breakdowns.
- **Myth-Buster Matrix**: Sourced articles on Tantra, Diksha, Kundalini, and lifestyle.
- **Quiz Arena**: Puranic trivia, Shakti Peetha matching game, and verse assembly puzzles.

## Tech Stack
- React (TypeScript)
- Vite
- Tailwind CSS
- Lucide React Icons
- PWA (manifest + service worker for offline reading and japa tracking)

## Theme
- **Mantra Night (Dark, default)**: Deep obsidian, muted gold, crimson.
- **Sattvic Day (Light)**: Warm parchment, amber, maroon.

## Getting Started

